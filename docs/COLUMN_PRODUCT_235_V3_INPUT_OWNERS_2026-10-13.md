## Import / review / stale law

`column.product.235.input.v1` binds component235, project B-BLOK, exact61FA and
separate FC09 hashes, field units, accepted factual receipt epoch, adoption hashes
and original receipt/sidecar/capture HEAD/TREE pins. The server obtains accepted
facts only from SHA-verified Git adoptions. Optional original JSON+sidecar pairs
are exact base64 bytes checked against those previously accepted independent pins;
no native response is synthesized, copied into Git, or re-decoded with guessed ABI.
Missing optional bytes reuse the accepted adoption, not a newly claimed native
read. Unknown receipt authority, source/units/component/epoch/pin drift or supplied
bad original bytes fail. Current analysis `result_epoch` is null and cannot be
supplied by a client to mint a qualified B5/B6 result. A hash of caller JSON is
integrity only. Future result acquisition needs a separate qualified contract.

All38 values start null. Group review records explicit person, document reference,
time with timezone, source, factual epoch, exact group-input hash and origin
(PROJECT_DOCUMENT, USER_DECLARATION, SYNTHETIC_TEST). This is a user/project review
declaration, not independently authenticated supervisor/native approval. Native
field authority is never granted by the checkbox/form. The existing material
basis types validate reviewed strength entries; they remain unbound to factual
material identity. Edits remove the affected review. No field fallback exists.

235 context selection resets the draft; importing a valid saved packet retains
its exact review records. Context/input/import/review changes clear all results,
drawing and exports atomically. An import first invalidates backend state before
file parsing; even malformed JSON cannot leave the old backend result active.
Backend revision/result checks plus R1 immutable context/epoch tokens gate every
calculation, review acknowledgement, error and export. Unsupported production
controls show BLOCKED, never a calculated FAIL. Actual calculated scope is limited
to independent reviewed leaf results; complete production design remains blocked.

`.column-product-venv`, preserves foreign environments, verifies pinned versions,
forces PyYAML6.0.2 source build with PYYAML_FORCE_LIBYAML=0 and no cached native
